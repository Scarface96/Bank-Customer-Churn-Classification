# 🏦 Bank Customer Churn Classification

A machine learning project that predicts which bank customers are likely to leave (churn), using customer demographics and account activity. Four models are compared, and the results are published as an interactive report with a churn-risk calculator and a retention budget planner.

## 🌐 Live Report

**[scarface96.github.io/Bank-Customer-Churn-Classification](https://scarface96.github.io/Bank-Customer-Churn-Classification/)**

The report is generated by the Python code in `analysis/` and republished automatically by GitHub Actions on every push to `main`. It includes:

- **Who leaves the bank?** Churn rate by country, age, products held and activity
- **Which model should the bank trust?** ROC curves for four cross-validated models
- **What drives the prediction?** Permutation importance from the best model
- **Where should retention effort go?** Lift by risk decile: the riskiest fifth holds ~62% of churners
- **Score a customer:** an in-browser churn-risk calculator, with the factors pushing risk up or down
- **How many customers should the bank call?** A retention budget planner: set offer cost, customer value and success rate to find the most profitable cut-off

### Model comparison (held-out 20%)

| Model | CV ROC AUC | Test ROC AUC |
|-------|-----------:|-------------:|
| Gradient boosting | 0.864 | 0.863 |
| Random forest (tuned) | 0.858 | 0.862 |
| Explainable logistic regression | 0.842 | 0.845 |
| Logistic regression (original) | 0.763 | 0.775 |

The **explainable logistic regression** is new: it adds a curved age term and treats product count as a category. That lifts the simple, transparent model from 0.77 to 0.84 AUC, close to the tree models, and it's the model that powers the in-browser calculator.

## 📋 Overview

Keeping an existing customer is far cheaper than winning a new one. This project uses a dataset of **10,000 bank customers** to identify who is at risk of churning so the bank can act early.

**Target variable:** `Exited` (1 = customer left the bank, 0 = stayed)

## 🗂️ Dataset

`Bank_Churn.csv` — 10,000 rows, 13 columns:

| Column | Description |
|--------|-------------|
| `CreditScore` | Customer's credit score |
| `Geography` | Country (France, Germany, Spain) |
| `Gender`, `Age` | Demographics |
| `Tenure` | Years as a customer |
| `Balance` | Account balance |
| `NumOfProducts` | Number of bank products held |
| `HasCrCard`, `IsActiveMember` | Card ownership and activity flags |
| `EstimatedSalary` | Estimated annual salary |
| `Exited` | Churn flag (target) |

## 🔍 Workflow

1. **Exploratory analysis** — pair plots, a correlation heatmap, and box/bar plots of every feature split by churn status
2. **Feature engineering** — dropped ID columns and created two new features:
   - `balance_to_income` = Balance ÷ EstimatedSalary
   - `income_v_product` = EstimatedSalary ÷ NumOfProducts
3. **Encoding** — one-hot encoded `Geography` and `Gender`
4. **Train/test split** — 80/20
5. **Logistic Regression** — baseline model, evaluated with accuracy, precision, recall, F1, confusion matrix and ROC curve
6. **Threshold tuning** — used the precision-recall curve to lower the decision threshold to ~0.32
7. **Random Forest** — hyperparameters tuned in two rounds with `RandomizedSearchCV`
8. **Feature importance** — ranked the features driving churn predictions

## 📊 Results

| Model | Test Accuracy | Notes |
|-------|---------------|-------|
| Logistic Regression (threshold 0.5) | **81.3%** | Precision 0.62, recall 0.22, ROC AUC 0.77 |
| Logistic Regression (threshold 0.32) | — | Recall roughly doubled to 0.45 at precision 0.49 |
| Random Forest (tuned) | **86.0%** | `n_estimators=910`, `max_depth=12`, `min_samples_leaf=5`, `max_samples=0.6` |

**Takeaway:** the default logistic regression looks accurate but misses most churners (low recall). Lowering the threshold catches far more of them, and the tuned Random Forest gives the best overall accuracy.

## 🚀 How to Run

```bash
pip install -r requirements.txt
python -m pytest            # run the tests
python -m analysis.build    # run the analysis and build site/index.html
```

Open `site/index.html` in a browser to see the report. The original notebook still works too:

```bash
pip install jupyter matplotlib seaborn
jupyter notebook "Bank Customer Churn Classification.ipynb"
```
